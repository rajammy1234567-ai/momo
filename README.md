# Momo Brand - MERN Website

A premium MERN stack website for a Momo brand, focusing on Franchise opportunities.

## Tech Stack
- **Frontend**: React (Vite), Framer Motion, Lucide Icons, Vanilla CSS (Utility-first approach)
- **Backend**: Node.js, Express, MongoDB
- **Database**: MongoDB (Local)

## Sections
1. **Home**: High-impact hero section with cinematic imagery.
2. **About**: Our story and core values.
3. **Franchise Form**: Lead generation for business partners.
4. **Social Media Timeline**: Interactive simulated social feed.
5. **Contact Us**: Direct communication channel.
6. **Footer**: Quick links and brand info.

## Setup
1. Ensure MongoDB is running on `mongodb://localhost:27017/momo_brand`.
2. Run `npm install` in the root directory.
3. Run `npm run dev` to start both frontend and backend concurrently.
